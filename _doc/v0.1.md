# v0.1（2026-10-13）— 獨立建倉第一版

`lean4mini` 由 `muse-computer/compiler/lean-self` 遷出為獨立專案的第一個定版。
以自舉不動點（IR₀ = IR₁ = IR₂）為驗收標準，本版為綠燈。

## 內容

- `Main.lean`（約 1080 行）：stage0，Lean 4 寫的詞法/語法分析、AST→IR、堆疊 VM、自舉驅動。
- `compiler.mini`（約 680 行）：自舉編譯器，MiniLang 寫的單趟編譯器（stdin 讀原始碼、stdout 印 IR）。
- `examples/`：`fib / while / array / string / io` 五個範例（遞迴、全域＋迴圈、陣列＋前向呼叫、
  字串＋`putc`、I/O＋`&&`/`||` 短路）。
- `difftest.py`：隨機程式差異測試（stage0 vs stage2 的 IR 比對）。
- IR：18 條堆疊機指令 `(opcode, operand)`，文字格式為整數串流（`memsize, op₀, arg₀, …`）。

## 本版變更（相對遷入時）

1. **修全域指標索引 bug**：`let s = "hi!"; print s[0]` 舊版印出 `1`（變數槽位址）而非 `104`。
   `pushBase` 對全域變數少了一次 `mload` 解參照。`Main.lean` 新增 `CState.garr`、
   `compiler.mini` 新增 `gisarr` 區分全域陣列（底址＝常數位址）與全域變數（底址＝解參照後的值），
   讀寫索引（`x[i]`、`x[i] = e`）共用同一邏輯。兩邊同步改，不動點保持。
2. **補 `examples/`**：遷入時 `README`/`bootstrap.sh` 引用了 `examples/*.mini` 但目錄不存在；
   本版補上五個範例，並修正 `array.mini` 排序（單趟限制：`array buf` 須在用它的 `fn` 之前）。
3. **`compiler.mini` 容量檢查**：`src 80000 / tok 30000 / code 60000 / 全域 2000 /`
   `函式 500 / 呼叫點 3000`，超限報 `fail(70-76)`，不再靜默寫壞。
4. **`minic run -i 輸入檔`**：分離程式輸入與 shell stdin；
   `run examples/io.mini -i /tmp/io.in`，無 `-i` 維持舊行為（`</dev/null`）。
5. **新增 `difftest.py`**：含全域字串索引回歸 case，`python3 difftest.py 30` 全過。
6. **文件**：`README` 補 `-i`、單趟限制、容量表；新增 `AGENTS.md`（建置順序、三 gate、雙實現同步規則）。

## 驗證結果

- `lake build`：成功（`leanprover/lean4:v4.20.0`）。
- `./bootstrap.sh`：自舉成功。
  stage0：`2954` 條指令、記憶體 `306969` 格；stage1/2 各產生 `15619` 字元 IR（VM 執行約 30ms）；
  `IR₀ = IR₁ ✔`、`IR₁ = IR₂ ✔`；五個範例 stage2 vs stage0 全 ✔。
- `python3 difftest.py 30`：`30/30 passed`。

## 已知限制（下版候選）

- 字串無跳脫（`"a\"b"`、`"\n"`），兩邊詞法須同步改。
- 只有 `//` 註解；無 `for`/`break`/`continue`、無區域陣列；全 `Int`、無型別系統。
- 無 IR 優化（常數折疊、peephole、字串駐留）。
- `exec` VM 尚無 Lean 正確性證明；無 `--trace` 除錯模式。
